Case 01 / Live personal AI foundation

A personal AI system that remembers what matters.

Most AI tools begin every conversation close to zero. The context lives in one chat, the files live somewhere else, and every job gets routed through whichever model happens to be open.

I wanted one interface that could remember the durable parts, retrieve the right project knowledge, use the computer when needed and still stop for human judgment where it matters.

Live now

Select a layer

One conversation. Six jobs underneath it.

Each layer has a narrow responsibility. Select one to see what it adds.

01

Hermes

Interface + runtime

The desktop conversation is the front door. Hermes can search, edit files, run code, control applications and continue work across sessions instead of only returning text.

ExampleTurn an approved portfolio plan into tested local pages, then show the result for review.

02

Hindsight

Long-term memory

Hindsight stores durable facts, decisions and personal context. It helps the system remember why a choice was made without loading an entire history into every prompt.

ExampleRemember that old ghostwriting work is evidence of skill, not a current business direction.

03

QMD

Canonical knowledge

QMD searches curated project documents locally. Memory answers “what matters about Shane?” while QMD answers “what does the actual project record say?”

ExampleRetrieve the source-backed PHASE decision instead of trusting a stale recollection from chat.

04

Skills and tools

Procedures + action

Skills load proven workflows only when a task needs them. Tools provide the hands: browser control, code execution, files, research, desktop actions and scheduled work.

ExampleLoad the PDF workflow, extract a client report, then use the verified figures in a case study.

05

Model routing

Cost + capability

Bounded, reversible work can go to a local model. Architecture, security, difficult creative judgment and consequential actions get stronger review. The route follows the risk of the job, not habit.

ExampleUse local compute for repetitive classification, then escalate the final strategic synthesis.

06

Review boundaries

Authority + verification

The agent can prepare and test work, but sensitive, expensive, external or irreversible steps remain approval-gated. Completion means the normal path was exercised, not merely that files exist.

ExampleBuild and verify a local redesign, but never publish it without a separate decision.

A normal task

Intent enters once. Context and capability assemble around it.

  1. 01Understand

    Hermes reads the request, current project state and authority boundary.

  2. 02Retrieve

    Memory and canonical documents supply only the context the task needs.

  3. 03Route

    The system chooses tools and model strength according to cost, risk and reversibility.

  4. 04Act

    It performs the work directly where authorized rather than returning a list of instructions.

  5. 05Verify

    Tests, read-backs and visual checks decide whether the result is actually finished.

Being built / Not presented as live

Workforce becomes the governance layer above Hermes.

The live foundation already handles conversation, tools, memory, knowledge and model routes. PHASE Workforce is being developed as the visual authority for missions, approvals, costs, canon and review lineage, with a Resource Governor deciding how much time, compute and autonomy a task receives.

Workforce→Resource Governor→Hermes→Models + tools

What the system changes

Less repeated setup. Better continuity. Stronger review where it counts.

Continuity
Projects can retain decisions and boundaries across sessions.
Economy
Cheap local routes handle bounded work; expensive capability is used deliberately.
Control
External and irreversible actions stay behind explicit approval gates.
Compounding
Useful procedures become reusable skills instead of being rediscovered each time.

Hermes Agent is an open-source agent framework by Nous Research. This page describes my personal setup and architectural direction, not the default product configuration.
